# Documentation

Start with the guide for the task you are doing. Planned capabilities are kept
separate from instructions for features that exist.

| Task | Guide |
| --- | --- |
| Understand what works and what is unfinished | [Status](status.md) and [support matrix](setup-support-matrix.md) |
| Try the limited alpha and report a result | [Alpha testing](alpha-testing.md) |
| Prepare a new computer and understand the installation plan | [Installation](installation.md) |
| Start an already configured dashboard | [Start the dashboard](start-dashboard.md) |
| Set up connections and start work | [Getting started](getting-started.md) |
| Configure SSH and troubleshoot authentication | [SSH setup](ssh-setup.md) |
| Troubleshoot Botainer, sign in an agent, rebuild images or update software | [Botainer maintenance](maintenance.md) |
| Give an agent setup instructions | [Agent setup guide](agent-setup-guide.md) |
| Launch, reconnect, detach or stop | [Sessions](sessions.md) |
| Edit project, connection or dashboard settings | [Configuration](configuration.md) |
| Use agents directly on a host | [Host agents and warnings](host-agents.md) |
| Understand trust and security boundaries | [Security](../SECURITY.md) and [entry-point inventory](engineering/security-entry-points.md) |

For development, see [architecture](architecture.md),
[dependencies](dependencies.md), the [development guide](engineering/README.md),
[validation gates](engineering/gates.md),
[dependency updates](engineering/dependency-updates.md), and
[source distribution](engineering/publication.md).
